# 원하는 포즈로 이미지 만드는 도구

## 도구 설명
- 참조 사진에서 OpenPose로 관절(뼈대)을 뽑고, 그 뼈대를 ControlNet 조건으로 넣어 **같은 자세의 다른 인물·장면**을 만듭니다.
- 모델: Stable Diffusion 1.5 + `lllyasviel/control_v11p_sd15_openpose` (FLUX.2에는 공식 포즈 ControlNet이 없어, 무료 Colab T4에서 돌아가는 비슷한 확산 모델을 썼습니다)

## 사용법
1. GitHub의 `pose_tool.ipynb`를 Colab에서 엽니다.
2. 런타임 유형을 **T4 GPU**로 바꾸고, 위에서부터 셀을 순서대로 실행합니다 (GPU 확인 → 설치 → 모델 로드 → 사진 준비 → 포즈 추출 → 생성 → 저장).
3. `samples/`에서 참조 사진(`pose_XX.png`), 뼈대(`pose_XX_skeleton.png`), 결과(`output_XX.png`)를 확인합니다.

## 테스트 결과
참조 사진 2장은 Gemini로 만든 전신 사진입니다.

- 포즈 1: 의자에 옆으로 앉은 자세 → 프롬프트: an astronaut in a white space suit on the moon, photo → 결과: 무릎을 굽혀 앉은 자세는 맞았지만, 의자는 그려지지 않아 허공에 앉은 모습이 되었습니다
- 포즈 2: 오른손을 높이 든 자세 → 프롬프트: a knight in shining armor in a medieval castle, photo → 결과: 선 자세와 팔 위치는 대체로 맞았고, 인물·의상·배경은 프롬프트대로 바뀌었습니다
- 같은 포즈 + 다른 프롬프트(요리사·슈퍼히어로·로봇): 자세는 모두 유지되고 직업·의상·배경이 바뀌었습니다. 다만 얼굴이 뭉개지고, 로봇은 다리 부분이 이상하게 나왔습니다
- 같은 프롬프트(공장 작업자) + 다른 포즈: 자세는 포즈 사진대로 바뀌었지만, 두 장이 같은 사람으로 나오지 않았고 성별도 참조 사진과 달랐습니다
- 포즈 세기(0.5 / 1.0 / 1.5): 0.5에서는 자세가 느슨해지고 손가락이 뭉개졌습니다. 1.0이 가장 안정적이었고, 1.5에서는 손 모양이 또렷해졌지만 몸이 딱딱하고 부자연스러워졌습니다

## 한계
- 포즈(뼈대)만 가져오므로 원본 인물의 얼굴·성별 같은 동일성은 유지되지 않습니다
- 의자 같은 소품은 뼈대에 담기지 않아, 앉은 자세에서 의자가 사라질 수 있습니다
- 손가락·얼굴처럼 작은 부분은 자주 뭉개집니다
- 망토처럼 몸을 덮는 의상을 프롬프트로 넣으면 자세가 가려져 잘 보이지 않습니다
